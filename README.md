# 현이방장의 데스노트

카카오톡 단톡방 **대화 내보내기** 파일을 올리면, 참여자별 누적 대화 수·마지막 대화일(D+N)·상태(활발/보통/저조/휴면)를 보여주고, 골라낸 이름을 데스노트에 적어 두는 아이폰용 웹앱입니다.

- 주소: https://kisunge.github.io/deathnote/
- 아이폰 `.zip`, PC·안드로이드 `.txt` 내보내기를 모두 읽습니다.
- **파일은 브라우저 안에서만 처리되고 어디로도 전송되지 않습니다.** 데스노트에 적은 이름도 그 기기에만 저장됩니다.

## 쓰는 법 (아이폰)

1. 카카오톡 채팅방 → 오른쪽 위 ≡ → 톱니바퀴(설정) → 대화 내용 내보내기 → 텍스트 메시지만 보내기
2. 공유 창에서 **파일에 저장**
3. 이 페이지에서 **파일 선택** → 저장한 `.zip`을 그대로 선택

사파리 공유 버튼 → **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 한계

- 내보낸 기간 안의 대화만 봅니다. 한 번도 말하지 않은 사람은 파일에 없어서 나타나지 않습니다.
- 카카오톡은 닉네임 변경을 기록하지 않으므로, 이름을 바꾼 사람은 다른 사람으로 집계됩니다.
- PC 카카오톡 내보내기는 동기화된 분량만 담겨 앞부분이 잘릴 수 있습니다.
